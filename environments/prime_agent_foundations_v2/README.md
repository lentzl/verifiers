# Prime Agent Foundations V2

This environment measures the official Prime Agent harness through observable behavior.
It covers exact IPython execution, persistent kernel state, resumed conversation state,
explicit child-result delivery, and child cancellation. It does not inspect Prime Agent
session internals or depend on private ACP metadata.

The five families are infrastructure checks rather than a complete coordination
curriculum. Pair them with natural delegation, ownership, and externalization tasks.
Use `instance_offset` to keep parameterized training and evaluation instances disjoint.
